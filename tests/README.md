# Проверка симулятора

Запускайте команды из корня репозитория. Для проверки расчётов достаточно Node.js.

```sh
node tests/physics.cjs
```

Скрипт извлекает расчётный код из HTML, проверяет пять энергий прямоугольной ямы и коэффициент прохождения ниже, на уровне и выше вершины прямоугольного барьера. Также проверяются формулы и таблицы потенциала.

Для проверки интерфейса установите Playwright и Chromium.

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.cjs
```

Браузерный тест открывает локальный HTML, переключает вкладки, меняет параметры и проверяет отображаемые результаты, обработку ошибок и размеры страницы на узком экране.
